Installation
============

The package requires Python 3.12 or later. From the repository root, create and activate a virtual environment:

.. code-block:: console

   python3 -m venv .venv
   source .venv/bin/activate

On Windows, use ``python`` to create the environment and the appropriate
activation command for your shell.

Install the package:

.. code-block:: console

   python -m pip install -e .
